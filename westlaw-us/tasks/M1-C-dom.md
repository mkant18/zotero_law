## Deliverables
1. `test/helpers/fakedom.mjs`: a tiny fake DOM for tests (no npm). `el(tag, attrs, ...children)` where children are elements or strings; elements expose `tagName`, `id`, `className`, `classList.contains`, `getAttribute`, `children`, `parentNode`, `textContent` (concatenated descendant text), `querySelector`, `querySelectorAll` (return arrays). Selector support: `tag`, `#id`, `.class`, `[attr]`, `[attr="v"]`, `[attr*="v"]`, compounds (`li#filedate`, `a[href*="/Document/I"]`), descendant (space) and child (`>`) combinators, and comma lists. `makeDoc({ title, body })` returns a document with `title`, `documentElement`, `querySelector(All)`. Include self-tests for the selector engine in dom.test.mjs.
2. `dom.js` (prefix `wlDom`):
   - `wlDomReadPageContext(doc, url)` → `{ ok, config:{ guid, contentType, relatedInfoHost }, secrets:{…}|null, ambiguous, reviewReasons }` — adapted from the probe (scan `<script>` text for the allowlisted keys; validate GUID `^I[0-9a-f]{32}$`; duplicates with different values → ambiguous). Never include token values in `config` or `reviewReasons`.
   - `wlDomInspectCaseReadiness(doc, url)` → `{ isCase, capability:"service"|"dom-only"|null, reason }` implementing plan §7 detectWeb policy: requires host `1.next.westlaw.com`; opinion header present (`#co_docHeaderTitleLine` or `#co_docHeaderCitation`); config ContentType `Cases` corroborated by title segment `| Cases |`; config missing but title + case DOM agree → dom-only; explicit non-Cases ContentType conflicting with a stale Cases title → not a case; URL/title alone → not a case. For `/Document/<GUID>/` URLs the URL GUID must equal config GUID (mismatch → not ready, reason `identity-mismatch`); `/Link/` URLs rely on config/header-link GUID.
   - `wlDomReadFacts(doc)` → `DomFacts` (CONTRACT): header name from `#co_docHeaderTitleLine` (cleaned; strip a trailing ` | Cases | …` if present); header list `#co_docHeaderCitation > li` — the list can appear TWICE (sticky header): dedupe by normalized text; classify each li semantically (court line = first li that is not a date/citation/page-count; date = parses via `wlTextParseUSDate`; page count = `/^\(Approx\. \d+ pages?\)$/`; citations = `wlRepFindCitations` on the li text; an li with an unknown reporter-like pattern → `{kind:"unparsed"}`), with ID variants (`courtline`/`chapter`, `filedate`, `citeN`/`chapterN`) used only as corroboration. Dockets from `.co_docketBlock` (split `Nos.` lists; keep raw text cleaned, strip trailing period). Fallbacks: `.co_courtBlock` for court, `.co_cites` for citations. Conflicting duplicates (two different dates) → review reason `conflicting-header`. Never read `.co_title` wholesale; never read opinion paragraphs. Every string through `wlTextClean` (watermark scrub).
