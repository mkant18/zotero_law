## Deliverables
1. `src/translator.js` — entry points (these names are required by Zotero and stay unprefixed): `detectWeb(doc, url)`, `doWeb(doc, url)`; plus helpers prefixed `wlTr`.
   - `var wlTrVersion = "0.1.0";`
   - `detectWeb`: no network. `wlDomInspectCaseReadiness(doc, url)`; ready → `"case"`; not ready but header container absent (page still loading) → call `Zotero.monitorDOMChanges(<#co_docHeaderContainer or #co_document or body>)` ONCE per detect call and return false; otherwise false.
   - `async doWeb(doc, url)`: capture page context + DOM facts FIRST (frozen); classify court + select profile; if `capability === "service"` build requests (`wlSvcBuildRequests`) and `await wlSvcFetchAll(reqs, { request: (u, o) => ZU.request(u, o), setTimeout: setTimeout, clearTimeout: clearTimeout })`; read envelopes (`wlSvcReadEnvelope`) for A (`standard` or `texas`+`standard`) and B (`standard`,`westlaw`); after the requests, re-read the page context and if the GUID changed → ignore service results and reconcile DOM-only with review `identity-changed`; `wlRecReconcile`; `wlMapToZoteroFields(rec, {version: wlTrVersion})`; `wlMapValidateOutgoing` — if problems, drop the offending optional fields (history/shortTitle/url) and add `Westlaw review: validation-<code>` extra lines rather than aborting; then `var item = new Zotero.Item("case"); wlMapApply(fields, item); item.complete();` exactly once.
   - Secrets are only ever passed into `wlSvcBuildRequests`; never logged. `Zotero.debug` only with bounded codes: `"Westlaw US " + wlTrVersion + " profile=" + … + " A=" + category + " B=" + category + " status=" + …` (no URLs, tokens, names, text).
   - Any unexpected exception after DOM capture → still save a metadata-only item from the frozen DOM facts (review `translator-error`); only if DOM capture itself failed, rethrow (connector falls back — documented limitation).
   - No attachments, notes, creators. No `multiple` support (`detectWeb` never returns "multiple").
   - `var testCases = [];` at the end of the built file (Zotero requires the variable; live cases cannot be committed).
2. `tools/build-translator.mjs` — Node script: writes `westlaw-us/dist/Westlaw Advantage US.js` = JSON header block (translatorID = a fixed new UUID v4 you generate once and hard-code; label `Westlaw Advantage US (local)`; creator `local`; target `^https://1\\.next\\.westlaw\\.com/`; minVersion `5.0`; maxVersion `""`; priority 100; inRepository false; translatorType 4; browserSupport `gcsibv`; lastUpdated = current UTC `YYYY-MM-DD HH:MM:SS`), then the AGPL license comment (copy the probe's), then modules in order `text.js, reporters.js, cite-parse.js, profile.js, service.js, dom.js, map.js, reconcile.js, translator.js` with each file's trailing `if (typeof module …) { … }` guard removed and a `/* ---- <file> ---- */` separator, then `/** BEGIN TEST CASES **/\nvar testCases = [];\n/** END TEST CASES **/`. After writing, run `node --check` on it and fail on duplicate top-level function names across modules (report them).
3. `src/test/translator.test.mjs` — builds via the script (or imports its build function), loads the BUILT file into a vm context with fakes for `Zotero` (`Item` constructor recording fields and `complete` calls, `debug` capturing strings, `monitorDOMChanges`), `ZU.request` (mock responses keyed by styleIDs in the URL), `setTimeout/clearTimeout`, and fake-DOM documents from `helpers/fakedom.mjs`. Scenarios: G1-like Sanchez page + synthetic envelopes → one item with expected fields (caseName, court `5th Cir.`, date, docket, reporter fields, shortTitle, url, extra contains no `Medium:`), `complete` called once; Texas page → Genre line + Texas court; A 401 → metadata-only item with tag `Westlaw: needs citation review` and B not requested; GUID changes between capture and after-requests → `identity-changed`; secondary-source page → detectWeb false and no requests; loading page → monitorDOMChanges called once; debug strings never contain `TEST-RT-0001` or `http`; no attachments/notes/creators; exactly the expected number of `ZU.request` calls (≤3).
